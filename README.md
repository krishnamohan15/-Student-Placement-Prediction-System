# 🎓 Student Placement Prediction System

A Machine Learning-based system that predicts whether a student is likely to be **Placed** or **Not Placed** based on academic performance, technical skills, extracurricular activities, and other student-related attributes.

The project includes data preprocessing, exploratory analysis, multiple classification models, model evaluation, feature-importance analysis, and an interactive prediction interface built using Gradio.

---

## 📌 Project Overview

Student placement is influenced by several academic, technical, and personal-development factors such as CGPA, coding skills, aptitude performance, communication skills, internships, projects, attendance, certifications, and interview performance.

The goal of this project is to develop a machine learning system that learns patterns from student placement data and predicts the placement status of a student.

### 🎯 Objective

The main objectives of this project are:

- Analyze student placement-related data.
- Clean and preprocess the dataset.
- Handle numerical and categorical features.
- Train multiple machine learning classification models.
- Compare model performance using standard evaluation metrics.
- Identify features considered important by the Random Forest model.
- Build an interactive student placement prediction interface.
- Save the trained machine learning model for future use.
